# Подарочный сертификат Туту — прототип лендинга

Прототип страницы продажи подарочных сертификатов Туту. Оплата и отправка не подключены, кнопки «Оплатить» и «Оставить заявку» показывают заглушку.

- Версия A, форма на этой же странице: `index.html`
- Версия B, лендинг и отдельная форма из 4 шагов: `index-b.html` и `buy.html`

## Как открыть локально

Статичный HTML, CSS и JS без сборки:

```bash
python -m http.server 4100
```

и перейти на http://localhost:4100.

## Файлы

- `site.css` — стили страниц;
- `ticket.css`, `ticket.js` — билет для печати и открытка для письма;
- `shared.js` — суммы, открытки, билеты, шаблоны поздравлений, карточки блоков;
- `landing.js` — билет в первом экране;
- `assets/`, `fonts/` — картинки и шрифт Tutu Sans.
